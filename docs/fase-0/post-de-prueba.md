Un focus group no sirve para saber cuántos. Sirve para saber por qué.

Es una de las confusiones más caras que veo en investigación de mercado: pedirle a una conversación de 7 personas lo que solo puede dar una encuesta.

Un focus group es una conversación guiada con un grupo pequeño de un perfil definido. Lo valioso no es la opinión de cada uno, sino lo que pasa entre ellos: cómo explican una elección, en qué se contradicen, qué objeción aparece solo cuando alguien se anima a decirla.

Sirve antes de un lanzamiento, antes de una campaña, para entender a quien no te compra o para preparar una encuesta.

No sirve si necesitas porcentajes del mercado, si el tema es demasiado íntimo para decirlo frente a otros o si la decisión ya está tomada.

Y una regla que uso para leer el resultado: un hallazgo sin cita es una opinión del analista.
